# Maleek Duckett

## GTM analytics series

Four projects built on the same CRM data from a fictional SaaS company (the data lives in a private repo, and every record is made up). They follow a lead from the moment it arrives to the quarter's forecast. Each one is graded against an answer key, so the results are checked, not guessed.

| Project | The question | Result |
|---|---|---|
| [lead-account-matching](https://github.com/maleekduckett/lead-account-matching) | Which company is this lead from, and who should call them? | 99.4% of leads with an account matched, with no wrong matches |
| [lead-scoring-sla](https://github.com/maleekduckett/lead-scoring-sla) | How hot is this lead, and did the team respond in time? | Found all 388 planted process problems. Hot leads met their 5-minute SLA only 58% of the time |
| [crm-data-hygiene](https://github.com/maleekduckett/crm-data-hygiene) · [dashboard](https://maleekduckett.github.io/crm-data-hygiene/) | How clean is the CRM, and what should be fixed first? | 75% of open pipeline dollars sat on deals with a high-severity problem |
| [pipeline-forecast](https://github.com/maleekduckett/pipeline-forecast) · [dashboard](https://maleekduckett.github.io/pipeline-forecast/) | How much will close this quarter, and is the pipeline healthy? | Back-tested five methods. The best missed by 14% on average, against 85% for rep Commit |
